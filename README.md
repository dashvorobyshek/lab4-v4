## Описание выполнения заданий

### Средняя сложность №4

Создан файл `task4.py`.

Реализована функция `factorial(n)`, вычисляющая факториал через `reduce` из стандартного модуля `functools`.

Для перемножения используется lambda-выражение. Начальное значение reduce равно 1, поэтому факториал нуля вычисляется правильно: `0! = 1`. Функция принимает целое неотрицательное число. При неправильном типе аргумента возникает TypeError, при отрицательном значении - ValueError. При запуске файла пользователь вводит число с клавиатуры. Некорректный ввод обрабатывается, после чего программа предлагает повторить ввод.

Контрольные примеры:

- `factorial(0)` возвращает `1`;
- `factorial(1)` возвращает `1`;
- `factorial(5)` возвращает `120`;
- `factorial(-1)` вызывает ValueError.

### Средняя сложность №6

Создан файл `task6.py`.

Реализована функция-генератор `prime_numbers(limit)`. Она выдаёт простые числа от 2 до указанной границы включительно.

Параметр limit задаёт верхнюю границу поиска, а не количество простых чисел. Для проверки числа перебираются делители, пока квадрат делителя не превышает проверяемое число. Найденные простые числа выдаются через yield. Генератор самостоятельно проверяет тип и значение границы. Проверки выполняются при начале перебора генератора. При запуске файла пользователь вводит границу с клавиатуры. Полученные значения собираются в список для вывода.

Контрольные примеры:

- при границе `0` результат `[]`;
- при границе `1` результат `[]`;
- при границе `2` результат `[2]`;
- при границе `20` результат
  `[2, 3, 5, 7, 11, 13, 17, 19]`;
- отрицательная граница вызывает ValueError при переборе.

### Средняя сложность №10

Создан файл `task10.py`.

Реализована функция `apply_functions(numbers, functions)`. Она принимает список чисел и список функций. Каждая функция применяется ко всем элементам исходного списка через map. Результаты преобразуются в списки.

В демонстрации используются три lambda-выражения:

- возведение в квадрат;
- умножение на 2;
- прибавление единицы.

Для исходного списка `[1, 2, 3, 4, 5]` получаются:

- квадраты: `[1, 4, 9, 16, 25]`;
- удвоение: `[2, 4, 6, 8, 10]`;
- прибавление единицы: `[2, 3, 4, 5, 6]`.

Каждая функция получает исходный список. Исходный список не изменяется.

При пустом списке чисел каждая функция даёт пустой список.
При пустом списке функций результат равен `[]`.

### Повышенная сложность №5

Создан файл `task5pov.py`.

Реализован собственный класс-итератор `SquareIterator`. Он выдаёт квадраты целых чисел от 1 до limit включительно.

В классе определены методы:

- `__init__` - проверка границы и создание начального состояния;
- `__iter__` - возврат самого итератора;
- `__next__` - получение следующего квадрата.

Граница должна быть целым неотрицательным числом. Проверки выполняются до сохранения состояния объекта.

После завершения последовательности метод __next__ вызывает StopIteration.

Состояние при повторном вызове iter не сбрасывается. Чтобы повторить последовательность с начала, нужно создать новый объект.

Контрольный пример для `SquareIterator(5)`:

- первый вызов next возвращает `1`;
- оставшиеся значения: `[4, 9, 16, 25]`;
- после завершения повторное преобразование в список даёт `[]`.

При границе `0` последовательность пуста.

### Повышенная сложность №9

Создан файл `task9pov.py`.

Реализована функция `pipeline(data, *steps)`. Она принимает исходные данные и функции обработки. Результат каждого этапа передаётся следующему.

В демонстрации используются три этапа:

1. `keep_positive` - отбор положительных чисел через filter.
2. `square_numbers` - вычисление квадратов через map.
3. `sum_numbers` - вычисление суммы.

Функции обработки рассчитаны на списки целых чисел.

Для исходного списка `[-3, -1, 0, 2, 4, 5]`:

1. После фильтрации получается `[2, 4, 5]`.
2. После возведения в квадрат получается `[4, 16, 25]`.
3. Итоговая сумма равна `45`.

Используемые этапы не изменяют исходный список.

Если этапы не переданы, pipeline возвращает исходные данные.
При обработке пустого списка показанная цепочка возвращает `0`.
